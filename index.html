Мои инструменты

Открытые инструменты для пентеста. Написаны на Python. github.com/whyasd666/t00ls →

// whyxss.py

Автоматизированный сканер XSS-уязвимостей. Обнаруживает reflected и stored XSS, тестирует формы и URL-параметры с обходом базовых фильтров.

$ python3 whyxss.py -u https://target.com
[+] Scanning for XSS vectors...
[+] Found: /search?q= → reflected XSS
[+] Payload: <script>alert(1)</script>
[!] 3 vulnerabilities found
Открыть на GitHub

// whyasdscan.py

Многопоточный сканер портов и сервисов с определением баннеров. Поддерживает CIDR-диапазоны, экспорт результатов и интеграцию с другими тулами.

$ python3 whyasdscan.py -t 192.168.1.0/24
[+] Scanning 256 hosts...
[+] 192.168.1.5:22 — OpenSSH 8.9
[+] 192.168.1.5:80 — Apache 2.4.52
[+] 192.168.1.10:445 — SMB open
Открыть на GitHub

// whytrix.py
